# ByteSpace - Next-Generation Online Learning Platform 🚀

A modern, responsive, and visually immersive educational web application built with **React 19**, **Vite**, **Lucide Icons**, and **Vanilla CSS**. Designed with rich dark aesthetics, 3D geometric accents, and dynamic interactive micro-animations.

---

## 🌟 Features Overview

- **Dynamic Hero Showcase**: Engaging headline, interactive search bar with quick tags, live student metrics badge, and floating 3D geometric accents.
- **Brand Partner Showcase**: Highlighted collaborations with top industry organizations.
- **Interactive Courses Catalog**:
  - Filter courses by multiple categories (Design, Development, Business, Data Science, etc.).
  - Real-time search query filtering.
  - Course cards featuring pricing, rating stars, instructor info, lesson counts, and enrolled student badges.
- **Course Detail Experience**:
  - Deep-dive course overview with interactive video player preview.
  - Collapsible curriculum modules with lesson durations and free preview indicators.
  - Instructor credentials and frequently asked questions.
- **Quick Course Preview Modal**: Instant popup modal to preview course specs and trigger fast enrollment.
- **Creator Studio Showcase**: Dedicated section showcasing creator monetization, student enrollments, and course authoring tools.
- **Community Testimonials**: Verified student and creator reviews with visual role indicators.
- **Interactive Cart Drawer**: Real-time slide-over cart drawer calculating subtotals, item removals, and checkout flow.
- **Authentication Modal**: Seamless Sign-In / Sign-Up tabbed modal with form validation and social login options.
- **Custom 404 Error Page**: Branded page-not-found route with floating 3D decorations and smooth navigation back to home.

## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- `npm` or `yarn`

### Installation
```bash
# Clone the repository
git clone https://github.com/Mehedii-07/ByteSpace_Mehedi.git

# Navigate into the project folder
cd ByteSpace_Mehedi

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build & Lint
```bash
# Run Oxlint to verify code quality
npm run lint

# Compile production bundle
npm run build

# Preview production build locally
npm run preview
```
